# Accessibility

Aim for WCAG 2.2 AA.
- Semantic HTML and logical heading hierarchy.
- Full keyboard navigation and visible focus indicators.
- Accessible names for icon-only controls.
- Alt text for meaningful images; empty alt for decorative images.
- Sufficient contrast; never communicate state by colour alone.
- Label all fields and associate errors with inputs.
- Accessible form status announcements.
- Accessible mobile menu states and controls.
- Respect `prefers-reduced-motion`.
- Do not trap focus except in a correctly managed modal/menu pattern.
- Readable text, touch-friendly controls, zoom support, narrow-screen usability.
- Descriptive links; avoid ambiguous repeated links.
