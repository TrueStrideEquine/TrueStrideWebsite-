# Cursor Rules

## Before substantial work
Read project brief, design, site map, architecture, responsive, motion, accessibility, engineering, assets, and content docs.

## Non-negotiable design
- **50% silver, 30% white, 20% black** overall palette.
- Cormorant Garamond headings; Inter body/UI.
- Luxury through simplicity, elegance, space, restraint.
- Horse-first bay thoroughbred hero; vehicle must not dominate initial load.
- Reveal vehicle imagery later on scroll.
- Transparent header over hero, solid light header after scrolling.
- Subtle Apple-like motion only.
- Every page fully responsive.
- Never invent TS-01 specs, safety claims, contact details, or testimonials.

## Workflow
Inspect before editing. State task scope. Change only what is required. Follow architecture; avoid unnecessary dependencies. Run checks. Summarise files changed and results. Do not silently expand scope.

## Phase gate
If asked for setup only, create base config, folders, and minimal valid routes only. Do not implement UI. Wait for explicit approval before design foundations/pages.

## Missing details
Use a clearly labelled placeholder or ask one concise question. Never fabricate brand assets, product specifications, contact details, or functionality.
